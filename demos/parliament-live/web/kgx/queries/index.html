Sample SPARQL queries

Each .rq file declares its target endpoint at the top. Open in your editor of choice, or copy into one of the kgx clients.

  • 01-fpkg-count-quads.rq — count every quad in the bundled store. Verified.
  • 02-fpkg-list-graphs.rq — enumerate named graphs with quad counts.
  • 03-fpkg-top-predicates.rq — top 20 predicates by usage.
  • 04-wikidata-current-uk-mps.rq — every sitting MP, against Wikidata.
  • 05-fpkg-appg-officers.rq — APPG officers joined to Members API ids.
  • 06-wikidata-uk-prime-ministers.rq — UK PMs with portraits; showcases label-merge + inline images + sortable date.
  • 07-wikidata-pm-ancestors-of-queen-mother.rq — which UK PMs are blood ancestors of the Queen Mother (Devonshire 4th Duke + Portland 3rd Duke).
  • 08-ddp-sitting-post-ge-2024.rq — verification: count of sitting Commons MPs whose seat started on/after 2024-07-04 in DDP. Currently 0; DDP is one Parliament behind.
  • 09-ddp-open-incumbency-year-distribution.rq — companion: year distribution of "open" Commons incumbencies. Today: 2019 → 650.

Adding a query: drop a .rq file in this directory (with the # Endpoint: header) and link it here.
