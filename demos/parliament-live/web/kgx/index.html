kgx — Knowledge Graph Exchange

Developer surface of Forgetmeknot Palace — a small graph navigator over UK Parliament APIs, plus a bundled SPARQL endpoint over ~558 k quads of openly-published RDF.

Demos

→ Curated SPARQL demos

Picture-rich Wikidata queries, cross-graph joins inside FPKG, plus one federation example. Each demo has a "Try in playground" button.

→ daisychain

Bead-spine exploration over UK MPs since 1900. Each chip on the bottom bead grows the chain; tap an older bead to undo. Same set engine as pivcab, surfaced as a notebook rather than a DAG.

→ pivcab

DAG view of the same engine: nodes, edges, two-pick combine bar (A ∪ B / A ∩ B / A ∖ B). The "show your work" view of a daisychain.

→ Thesaurus graph

Force-directed (auto-layout) view of the Parliament Thesaurus SKOS graph — broader / related / exactMatch links, coloured by relationship, nodes sized by degree. Drag, zoom, search, click a concept for its neighbours. Live from the bundled endpoint.

Try SPARQL

★ SPARQL studio

The rich client: a query catalogue grouped by dataset (APPGs, psephology, accountability, identity, treaties, thesaurus, DDP, Wikidata, EUR-Lex), fill-in-the-blank parameterised templates, a 📎 wizard if you don't know where to start, and one-tap links to the experimental pivot/daisychain labs. Multi-endpoint. Start here.

Playground

Minimal page — textarea, run, JSON output. ~3 KB; useful on a flaky connection or as a sanity check.

Flint SPARQL Editor

TSO's 2012-era editor (MIT). Loaded via jsDelivr's mirror of TSO-Openup/FlintSparqlEditor. Customise by passing ?endpoints=<url>.

YASGUI

Triply YASGUI 4.x (MIT). Tabbed, with chart / table / response views. Customise by passing ?endpoints=<url>.

SHACL checker

Validate live data against SHACL shapes in the browser (Google schemarama). A CONSTRUCT/DESCRIBE carves out a subgraph — one resource or a class sample — and the shapes check it. Multi-endpoint via the same endpoints.json.

HTTP endpoints (machine paths)

PathAuthWhat it is
/kgx/query public Local bundled Oxigraph. Read-only. SPARQL 1.1. /sparql is a legacy alias that 301-redirects here.
/api/sparql PROXY_PASSWORD Caching proxy to api.parliament.uk/sparql (the DDP store). Parliament's endpoint sends CORS so you don't strictly need this; we keep it for cache + a single TTL policy.
/api/now/, /api/members/, /api/hansard/, /api/cvotes/, /api/lvotes/ PROXY_PASSWORD Caching proxies onto the modern Parliament REST APIs. See the demo's CLAUDE.md for the routing table.
/_health public JSON liveness probe. Returns {ok, cacheEntries, authRequired}.

Registries & samples

  • /kgx/endpoints.json — the curated endpoint list every kgx client reads (FPKG, UK Parliament DDP, Wikidata × 3 mirrors, DBpedia, legislation.gov.uk). Add an entry, every client picks it up.
  • /kgx/queries/ — sample .rq files, each tagged with its target endpoint at the top.

Customising the clients

Want Flint or YASGUI pointed at your own SPARQL endpoints? Host an endpoints.json with the shape of ours on a CORS-readable URL, and visit /kgx/flint?endpoints=<url> or /kgx/yas?endpoints=<url>. No fork required.

For deeper customisation (namespaces, branding, default query, the set of toolbar buttons) the wrappers are ~150 lines of HTML and one inline script each — copy, edit, host wherever:

  • kgx/flint.html on GitHub
  • kgx/yas.html on GitHub
  • kgx/playground.html on GitHub

Source code & docs

  • forgetmenot on GitHub — the whole repo (CLI parl, JS library, skills, demos).
  • skills/ — one folder per UK-Parliament-adjacent API or dataset. Each has a SKILL.md (the contract Claude reads) and a reference.md (the full endpoint listing).
  • demos/parliament-live/CLAUDE.md — the 12 rules this demo follows (probe-then-render, defensive renderers, the proxy is the only path, OPL attribution, etc.).
  • skills/kgx-infra-cloud-containers — catalogue of the deployment-side gotchas we've actually hit (fly.io, GitHub Actions, Docker, Oxigraph CLI changes), with the commit each fix landed in.
  • docs/triple-stores.md — local lore on Parliament's three RDF triple stores (DDP, DD, internal) and which one api.parliament.uk/sparql actually fronts.
