Forgetmeknot Palace — SPARQL surface

Three browser-based SPARQL clients, plus a raw HTTP endpoint. All four talk to the same default endpoint: /kgx/query.

Clients

Playground

Minimal page — textarea, run, JSON output. ~3 KB; works offline once loaded.

Flint SPARQL Editor

Syntax-highlighted editor (TSO). Lower friction for hand-writing SPARQL.

YASGUI

Triply's tabbed editor + table / response / chart views. Heaviest, richest.

HTTP endpoint

GET /kgx/query?query=<sparql> with Accept: application/sparql-results+json (or omit Accept for XML).

Backed by Oxigraph, read-only. The legacy path /sparql 301-redirects here.

Other endpoints the clients can hit

Each client lets you switch endpoints. The registry lives at /kgx/endpoints.json — add an entry and every client picks it up.

  • UK Parliament DDP — via /api/sparql proxy (no CORS direct)
  • Wikidata — official, QLever (Freiburg), and OpenLink Virtuoso mirrors
  • DBpedia
  • legislation.gov.uk (invitation-only, listed for completeness)
