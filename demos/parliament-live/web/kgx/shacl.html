SHACL checker

Validate live data from a SPARQL endpoint against SHACL shapes, in the browser (Google schemarama). Defaults to this server's bundled store; switch to UK Parliament's DDP endpoint or any other from the registry.

You don't validate a whole database — you validate a subgraph. A SPARQL CONSTRUCT/DESCRIBE carves out the slice you care about and returns it as RDF; that is what SHACL checks. The extraction query is the scoping knob. To check related nodes, the query must pull them in (a bare DESCRIBE won't). The FPKG → Wikidata preset goes further: it joins the bundled store to Wikidata through the identity mappings we serve, then validates the merged graph. Sampling with LIMIT is a spot-check, not a full-store audit.
