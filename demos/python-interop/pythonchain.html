pythonchain

A library of fifty knowledge-graph chains — click a category button to pick one. Each chain walks through several entity types (people → universities → cities → countries; films → directors → other films), and each step has a ▶ Run button that fires real SPARQL at qlever.dev and renders the rows as a tile grid.

Under the hood: each chain is a TriG manifest in kgx:vocab terms, parsed by kgx_chain.py running as Pyodide-compiled WebAssembly. Same parser as the CLI. Filters and pivots use POSITIVE-shape SPARQL (no MINUS / NOT EXISTS) because closed-world negation across federated KGs conflates absence-in-data with absence-in-fact — see shared-components.md.
