pythonchain

Python reading kgx daisychain manifests in your browser via Pyodide + rdflib. The same kgx_chain.py the CLI uses, running here as WebAssembly. No server-side Python.

The tool reports each step as ✓ grounded (has a runnable SPARQL fragment + endpoint), ◐ partial (has a gloss but nothing executable), or ⚠ ungrounded (neither). The example chains show the structural shapes the FPKG runtime emits — Linear / Fork / Augment for the everyday cases, plus DAG ones with Union / Intersect / Difference set-ops, a multi-variant chain, and a cross-endpoint federation example — each with full grounding so the ▶ Run buttons fire real SPARQL at the declared sd:Service and render the actual rows. The kgx vocab privileges no specific knowledge graph: every target is just an sd:Service with an endpoint URL, whatever it points at.
