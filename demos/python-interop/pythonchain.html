pythonchain

Python reading kgx daisychain manifests in your browser via Pyodide + rdflib. The same kgx_chain.py the CLI uses, running here as WebAssembly. No server-side Python.

The tool tries to be honest about a real gap: today's manifests describe a chain's structural shape — lineage, branch tree, op names — but rarely the grounding (endpoint, SPARQL fragment per step, fusion plan) that would let a third-party tool actually execute the chain. Each step is reported as ✓ grounded, ◐ partial or ⚠ ungrounded. The Linear / Fork / Augment examples show today's emit; the Grounded + fused / Variants examples show the proposed shape (discussion only). The vocab privileges no specific knowledge graph — every target is an sd:Service with an endpoint URL.
